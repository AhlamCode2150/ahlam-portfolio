# Ahlam Codex

My personal coding portfolio. Live at https://ahlam-codex.netlify.app

A pointillist night scene that warps into the title, a framed marbled artwork that opens onto bone paper, then an index of work: folios, instruments, method and contact.

Plain HTML, CSS and JavaScript with GSAP + ScrollTrigger and Lenis. No build step.

```
index.html
css/style.css
js/main.js
images/      project screenshots (.webp)
```

Run locally: `python -m http.server` in this folder, then open http://localhost:8000.

The opening scene on its own: https://github.com/AhlamCode2150/ahlam-portfolio-hero
